# Expo SDK 57

An Expo Router starter for native mobile and web. The app runs natively in Expo Go on your phone from Buildra's Metro preview, while the dashboard phone frames render the web build of the same code.

Run `bun install`, then `bun run dev`. Buildra injects the Metro port, host, and public origin. Run `bun run verify` before handing off a change; it type-checks and exports web, iOS, and Android bundles.

The UI kit is HeroUI Native on Uniwind with Tailwind 4. All kit imports, provider wiring, CSS, and preset themes live under `components/ui/`; screens use its Button, Card, Chip, and Sheet adapters. See [Design](AGENTS.md#design) and the [UI kit skill](.agents/skills/use-ui-kit/SKILL.md). `theme.css` chooses calm, bold, or structured with one import.

Metro preserves its transient-file exclusions and applies `withUniwindConfig` to the kit stylesheet. The SDK 57 Babel preset supplies the Worklets transform; Uniwind needs no separate Babel plugin. `uniwind-types.d.ts` is generated by Metro.

HeroUI Native does not recommend web usage. Validate the dashboard's react-native-web preview and the published static export alongside Expo Go; export success alone does not prove interactive rendering. If web rendering fails, replace `components/ui/` with Uniwind-only React Native adapters retaining its exports, provider, and stylesheet paths.
